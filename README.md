E-Commerce Power BI Analytics Dashboard
• Designed a Star Schema model (1 Fact, 3 Dimensions) in Power BI to analyze e-commerce retail transactions, improving query performance and visualization speed.
• Processed and cleaned transaction logs in Power Query by filtering cancellations/returns and engineering custom calculated columns for net line revenue.
• Developed DAX measures for core business KPIs including Total Revenue, Orders, Average Order Value (AOV), and Month-over-Month (MoM) growth %.
• Built a 2-page interactive report with dynamic cross-filtering, top-N product rankings, and geographic breakdowns to drive executive decision-making.
